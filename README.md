# Интерактивные генпланы

Исходники интерактивных генпланов ЖК «Рекорд» и ЖК «Самолёт» (очереди 1–6), плюс матрица ЖК «Самолёт».

Редактируемые страницы лежат в корне рядом со скриптами (`genplan_core.js`, `jk_logic.js`, данные очередей) и каталогами `assets/`, `build/`, `uploads/`. В папке `Автономные/` — самодостаточные HTML-копии тех же страниц.

- ЖК «Рекорд» — `Генплан интерактивный.dc.html`
- ЖК «Самолёт» 1–6 — `Генплан Самолет 1 интерактивный.dc.html` … `Генплан Самолет 6 интерактивный.dc.html`
- Матрица — `Матрица ЖК Самолет.dc.html`

**«Самолёт» 2** — файл `Генплан Самолет 2 интерактивный.dc.html`.
